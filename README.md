# branddi email assets

Imagens públicas das newsletters e emails da Branddi.

**Este repo precisa continuar público.** `raw.githubusercontent.com` exige token de
autenticação em repo privado, e clientes de email não enviam token — se o repo fechar,
as imagens param de carregar em toda campanha.

## URL das imagens

```
https://raw.githubusercontent.com/revops-branddi/email-assets/main/NOME-DO-ARQUIVO
```

## Migração do repo antigo

Os arquivos mantêm nome idêntico ao repo pessoal anterior
(`RogerBranddi/branddi-email-assets`, branch `master`). Para migrar um email antigo,
basta um find/replace:

```
RogerBranddi/branddi-email-assets/master   →   revops-branddi/email-assets/main
```

> **Atenção:** isso só vale para emails ainda não disparados. As campanhas já enviadas
> carregam a URL antiga no momento em que o destinatário abre a mensagem — não há como
> reescrever o que já saiu. O repo antigo precisa continuar público e intocado.

## Convenção de nome

Sem acento, sem espaço, sem maiúscula, com sufixo de ano.
Ex.: `blog-buy-box-amazon-2026.jpg`
